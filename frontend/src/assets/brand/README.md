# Marka varlıkları

- AKIŞ ürün logoları kullanıcı tarafından 25 Eylül 2026 tarihinde sağlandı.
- İnnova logoları kullanıcı tarafından sağlanan `İnnova Kurumsal Kimlik/Logo Seti` paketinden alındı.
- Dosyaların oranı, rengi ve çizimi değiştirilmemelidir.
- Açık yüzeyde `innova-logo.svg`, koyu yüzeyde `innova-logo-white.svg` kullanılır.
- Kurumsal yayına çıkmadan önce marka sahibi kullanım onayı ayrıca doğrulanmalıdır.
